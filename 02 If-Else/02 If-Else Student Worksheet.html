Adding else — The "Otherwise"

⬜
✓
Listen: instructor explains else
Java — FRC Example
if (buttonPressed) { shooterSpeed = 0.8; // button pressed → fire! } else { shooterSpeed = 0.0; // button NOT pressed → stop }
💬 Plain English: IF A button → shoot  |  OTHERWISE → stop
✓
The robot always does one of two things — never both, never nothing
✓
else runs only when the if condition is false

Multiple Choices with else if

⬜
✓
Listen: instructor explains else if
Java — Drive Speed Control
if (throttle > 0.8) { driveSpeed = 1.0; // full power } else if (throttle > 0.4) { driveSpeed = 0.5; // half power } else { driveSpeed = 0.0; // stop }
💬 The computer checks top-to-bottom and stops at the first true condition
✓
Only ONE branch runs, even if multiple conditions are true
✓
Order matters! More specific conditions go first
